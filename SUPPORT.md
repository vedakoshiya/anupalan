# Support & Community Help

Thank you for using **Anupalan (અનુપાલન / अनुपालन)**!

Here are the best ways to get help, ask statutory compliance questions, report issues, and connect with other developers and tax practitioners.

---

## 🧭 Where to Seek Help

### 1. Statutory Interpretation & AI Questions
If you have questions about how Anupalan parses a specific CBIC circular, GST notification, Section 43B(h) rule, or dialect term:
* Open a discussion or inquiry in [GitHub Issues](https://github.com/vedakoshiya/anupalan/issues).
* Include the query text, language used (e.g. Gujarati, Gujlish, Hindi, English), and the expected gazette citation.

### 2. Bug Reports & False Citations
If you encounter a software bug, unhandled edge case, or citation discrepancy:
* Check [Existing Issues](https://github.com/vedakoshiya/anupalan/issues) to see if it has already been reported.
* If not, file a new report using our [Bug Report Form](https://github.com/vedakoshiya/anupalan/issues/new?template=bug_report.yml).

### 3. Adding New State Gazettes & Tax Rules
Want to add support for Maharashtra, Tamil Nadu, Karnataka MSME schemes or new CBIC notifications?
* Submit a request using our [Statutory Instrument Request Form](https://github.com/vedakoshiya/anupalan/issues/new?template=statutory_update.yml).
* See the [Contributing Guide](CONTRIBUTING.md) to submit a pull request directly.

### 4. Security & DPDP Act Inquiries
For vulnerability reports or privacy queries under the Digital Personal Data Protection Act 2023:
* Please read [SECURITY.md](SECURITY.md) for direct disclosure instructions.
